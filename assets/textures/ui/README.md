# خلفيات الواجهة

ضع هنا الصورة الفنية لخلفية القوائم باسم:

```
menu_bg.png      (أو .jpg أو .webp)
```

يلتقطها المشروع **تلقائياً** عند البناء التالي ويستخدمها بدل المشهد
الإجرائي، بلا أي تعديل في الكود. يُضاف فوقها تعتيم متدرّج تلقائي حتى
يبقى النص مقروءاً.

## المواصفات

| | |
|---|---|
| الأبعاد الموصى بها | 2560×1200 أو أعلى |
| النسبة | عريضة قريبة من 2.1:1 |
| الصيغة | PNG أو JPG أو WebP |
| **مهم** | **بلا أي نص أو أزرار مرسومة داخل الصورة** |

الواجهة تُرسم فوق الصورة برمجياً. أي عنوان أو قائمة مرسومة داخلها
ستظهر مكررة.

## المنطقة الآمنة

يُستحسن إبقاء الثلث الأيمن هادئاً بصرياً (سماء أو ضباب) لأن قائمة
الأزرار تُرسم فوقه، والثلث الأيسر لأن الشعار يقع هناك.

## في غياب الصورة

يُرسم مشهد ليلي إجرائي بالشيدر: قمر وسحب وثلاث طبقات غابة وقصر بنوافذ
مضيئة ومطر وضباب. حادّ على أي دقة وحجمه صفر، لكنه مؤسلب لا واقعي.
