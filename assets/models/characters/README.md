# شخصيات اللعبة

أسقط ملفاً باسم `male.glb` أو `female.glb` هنا ويحلّ محلّ الشخصية
المفصليّة تلقائياً — بلا تعديل كود. الشرط الوحيد أن يحوي الملف
`Skeleton3D` و `AnimationPlayer`.

`CharacterModel` يربط حالات اللعب بأسماء الحركات بالكلمات لا بالاسم
الحرفي، فمجسّم يسمّي حركته `Run` وآخر يسمّيها `running_gun-cycle`
كلاهما يعمل. ويستبعد الحركات التجريبية التي يتركها الفنّانون
(`noexp`, `test`, `borrar`…). والطول يُوحَّد تلقائياً إلى 1.80 م
للرجل و1.68 م للمرأة مهما كان مقياس المصدر.

## الرخصة إلزامية

لا يُستخدم مجسّم إلا برخصة صريحة. عند إضافة أي ملف هنا، سجّل في
`MANIFEST.json` بجواره: المصدر، والمؤلّف، والرخصة، ورابطها. ورخص
النسبة (CC-BY) تتطلّب ذكر المؤلّف في شاشة الاعتمادات داخل اللعبة.
